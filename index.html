⚠ ആദ്യം GitHub Pages-ൽ തുറക്കുക

Downloads-ൽ നിന്ന് HTML നേരിട്ട് തുറന്നാൽ Google YouTube API-യ്ക്ക് Referer ലഭിക്കില്ല; “Requests from referer null are blocked” വരാം. ഈ ഫയൽ GitHub-ലെ Fads/index.html ആയി പ്രസിദ്ധീകരിച്ച് https://sudarsanankr.github.io/Fads/ വഴി തുറക്കുക.

⚙ API Setup — YouTube + TMDB
Keys ഈ browser-ൽ മാത്രം save ചെയ്യും. YouTube API v3-യും TMDB API-യും enable ചെയ്തിരിക്കണം. Google Cloud → Credentials → API Key → Website restrictions-ൽ https://sudarsanankr.github.io/* ചേർക്കുക. API keys chat-ൽ അയക്കരുത്.

നിയമപരമായ ഉപയോഗം: YouTube search results-ൽ embed അനുവദിച്ചിട്ടുള്ള വീഡിയോകൾ മാത്രമാണ് ഫിൽട്ടർ ചെയ്യുന്നത്. Embed അനുവദിച്ചതുകൊണ്ട് മാത്രം സിനിമയുടെ copyright streaming licence ലഭിക്കില്ല. Full movie കാണിക്കാൻ uploader/rights holder അനുമതി, അല്ലെങ്കിൽ സ്ഥിരീകരിച്ച Creative Commons/Public Domain അവകാശം ആവശ്യമാണ്. അതിനാൽ full-movie search Creative Commons filter ഉപയോഗിക്കുന്നു; ഓരോ വീഡിയോയുടെയും licence പ്രത്യേകം പരിശോധിക്കുക.

YouTube Error 101/150/153, private video, age restriction, region restriction എന്നിവ വന്നാൽ ആ വീഡിയോ FADS+ player-ൽ ലഭ്യമാകില്ല. മറ്റൊരു അനുവദനീയ വീഡിയോ തിരഞ്ഞെടുക്കുക. Browser-ൽ GitHub Pages HTTPS link വഴിയാണ് ഈ site തുറക്കേണ്ടത്; Downloads-ൽ നിന്ന് local HTML തുറക്കരുത്.
